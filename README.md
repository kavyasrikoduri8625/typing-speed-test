# Typing Speed Test

A desktop app built with Python and Tkinter that measures typing speed (WPM) and accuracy.

## Features
- Live green/red feedback while typing
- 60-second countdown timer
- WPM and accuracy calculation
- Restart with a new random sentence

## Technologies
Python, Tkinter

## How to run
1. Install Python 3
2. Download typing_speed_test.py
3. Run: python typing_speed_test.py
